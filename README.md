## Задача
Построить модель, которая по характеристикам квартиры предсказывает месячную
стоимость аренды в рублях для площадки «Квартал».

Исходный файл `rent_v28.csv` содержит выгрузку объявлений за
сентябрь–октябрь 2026 года. Одна строка соответствует одному объявлению.
Целевая переменная — `rent_rub`.

### Столбцы

| Столбец | Описание | Тип | Пример |
|---------|----------|-----|--------|
| `id` | Уникальный ID объявления | string | `599989b9` |
| `date` | Дата публикации | date | `2026-09-03` |
| `district` | Район | category | `Советский`, `Южный`, `Центральный`... |
| `house_type` | Тип дома | category | `панельный`, `кирпичный`, `монолитный`, `блочный`, `деревянный` |
| `year_built` | Год постройки | int | `1977` |
| `floors_total` | Этажность дома | int | `16` |
| `floor` | Этаж квартиры | int | `7` |
| `elevator` | Наличие лифта | binary | `да`/`нет` |
| `rooms` | Количество комнат | int | `2` |
| `area_total` | Общая площадь, м² | float | `62,1` |
| `area_living` | Жилая площадь, м² | float | `40,1` |
| `area_kitchen` | Площадь кухни, м² | float | `9,9` |
| `ceiling_height` | Высота потолков, м | float | `2,61` |
| `renovation` | Состояние ремонта | category | `евроремонт`, `косметический`, `без ремонта`, `дизайнерский`, `требует ремонта` |
| `furniture` | Мебель | category | `полностью`, `частично`, `нет` |
| `balcony` | Балкон/лоджия | binary | `да`/`нет` |
| `balcony_count` | Количество балконов | int | `0` |
| `parking` | Тип парковки | category | `открытая`, `подземная`, `нет` (пусто) |
| `metro_distance` | Расстояние до метро, м | int | `560` |
| `metro_walk_time` | Время до метро пешком, мин | float | `3,1` |
| `internet` | Интернет | binary | `да`/`нет` |
| `landlord_type` | Тип арендодателя | category | `агентство`, `собственник` |
| `photos_count` | Количество фотографий | int | `10` |
| `view_rate` | Процент просмотра | float | `2,4` |
| `views_count` | Количество просмотров | int | `3` |
| **`rent_rub`** | **Цена аренды, ₽/мес** | **int (target)** | `33 500` |


## Структура репозитория
- `notebooks/` — ноутбуки подготовки данных и моделирования
- `data/` — данные
  - `raw/` — сырые выданные файлы
  - `interim/` — сырая тестовая выборка
  - `processed/` — подготовленные данные
- `models/` — сохранённые модели и Pipeline
- `modules/` — переиспользуемые функции и классы
- `inference.py` — скрипт предсказания на тесте

## Окружение

Используется Python 3.12.

Все команды выполняются из корня репозитория в Windows PowerShell.

### Создание виртуального окружения

```powershell
python -m venv .venv
```

### Активация окружения

```powershell
.\.venv\Scripts\Activate.ps1
```

### Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### Запуск Jupyter Notebook

```powershell
python -m jupyter notebook
```

Основные библиотеки:

- NumPy и pandas — работа с данными;
- scikit-learn — предобработка, обучение и оценка моделей;
- Matplotlib и seaborn — визуализация;
- SciPy — статистические методы;
- joblib — сохранение и загрузка моделей;
- Jupyter — выполнение ноутбуков.
