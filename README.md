**Студент:** Суходолова Анна

## Задача
Построить модель, которая по характеристикам квартиры предсказывает месячную
стоимость аренды в рублях для площадки «Квартал».

Исходный файл `rent_v28.csv` содержит выгрузку объявлений за
сентябрь–октябрь 2026 года. Одна строка соответствует одному объявлению.
Целевая переменная — `rent_rub`.

### Столбцы
Вот таблица в формате Markdown. Я добавил обратные кавычки (`` ` ``) для названий колонок, чтобы они красиво выделялись в тексте:

| Колонка | Описание |
|---|---|
| `listing_id` | идентификатор объявления |
| `publication_date` | дата публикации объявления |
| `district` | административный район города |
| `house_type` | тип дома (материал стен) |
| `year_built` | год постройки дома |
| `floors_total` | этажность дома |
| `floor` | этаж квартиры |
| `elevator` | есть ли в доме лифт |
| `rooms` | число комнат |
| `total_area` | общая площадь, м² |
| `living_area` | жилая площадь, м² |
| `kitchen_area` | площадь кухни, м² |
| `ceiling_height` | высота потолков, м |
| `renovation` | состояние ремонта |
| `furniture` | меблированность |
| `appliances` | есть ли бытовая техника |
| `balcony` | число балконов и лоджий |
| `parking` | парковка |
| `metro_distance_m` | расстояние до ближайшей станции метро, м |
| `distance_to_center_km` | расстояние до центра города, км |
| `pets_allowed` | можно ли с домашними животными |
| `seller_type` | кто разместил объявление |
| `photos_count` | число фотографий в объявлении |
| `response_time_hours` | среднее время ответа арендодателя на сообщения, ч |
| `max_tenants` | максимальное число жильцов, указанное арендодателем |
| `rent_rub` | целевая переменная: стоимость аренды в месяц, ₽ |

## Структура репозитория
- `notebooks/` — ноутбуки подготовки данных и моделирования
- `data/` — данные
  - `raw/` — сырые выданные файлы
  - `interim/` — сырая тестовая выборка
  - `processed/` — подготовленные данные
- `models/` — сохранённые модели и Pipeline
- `modules/` — переиспользуемые функции и классы
- `inference.py` — скрипт предсказания на тесте
